# examples/llm — the LLM protocol suite

A snapshot of the request-conversion protocols that [Higress](https://github.com/alibaba/higress) `ai-proxy`
runs on this engine: OpenAI → Claude, OpenAI → Gemini, OpenAI → native Qwen (DashScope), and the
OpenAI-compatible passthrough family with its Qwen-compatible, Zhipu and OpenRouter variants, plus the
reusable `ToolsHook`. They are kept here as the engine's most demanding workload; the source of truth is the
Higress repository (`plugins/wasm-go/pkg/streamxform`), `scripts/sync-llm.sh` refreshes the copy.

## Tests

- The behavioural tests that ship with the protocols (commit point, stream detection, hold-and-bail, field
  inventory, memory order, key order, probing, shuffling, stop / tools streaming, robustness against garbage).
- `golden_test.go`: **differential against the reference implementations.** `testdata/*.jsonl.gz` was
  generated by Higress's buffered (official) conversions — for every hand-written case of the Higress test
  tables and 1000 random requests per protocol, the record holds the input, the configuration and the
  official output (or the official failure). The streaming protocol is built with the same configuration and
  run at chunk sizes 1 / 7 / 64 / 4096; the output must equal the official output field by field, numbers
  compared as literals (only `tools[].function.parameters`, which the buffered path round-trips through a map,
  is compared by value). The only tolerated differences are the ones documented for the plugin: the buffered
  path failing on a type error in a field the streaming path discards, and the known fallbacks (duplicate keys,
  parts the buffered path skips, http images the buffered path fetches, the `developer` role on the passthrough
  path).

Regenerating the golden files requires the Higress differential harness (`gen_golden_test.go` there, run with
`GOLDEN_DIR=<this dir>/testdata`).
